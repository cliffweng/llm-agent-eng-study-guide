# LLM & Agent Engineering Study Guide

A practical, no-fluff study guide for software engineers who want to get up to speed on LLM and agent engineering — whether that's for building real systems at work or for interview prep.

## How to use this guide

- Each topic in the left nav is a **standalone page you can read in ~10 minutes**.
- Every page follows the same shape: **why it matters**, **core concepts**, a **mental model**, **interview questions** with brief answer keys, and a short **watch list** of verified YouTube videos.
- Topics are ordered roughly from foundational to advanced. You can read them in order, or jump straight to the topic you need.
- Nothing here requires a backend, an API key, or a login — it's just reading.
